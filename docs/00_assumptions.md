# 仮定一覧（要検証事項）

このプロジェクトの各ドキュメント・スクリプトで使用している「事実確認できていない数値・前提」を
すべてここに集約する。本文中には `<!-- 推定 -->` コメントを付し、該当箇所からこのファイルへ
リンクバックできるようにする。**実案件を選定・入稿する前に、必ずASP・媒体の公式情報で裏取りすること。**

## 凡例
- 区分：Phase0（ヒアリング前提）/ 業界一般知見（相場感からの推定）/ 設計上の仮置き数値
- ステータス：要検証（未確認）/ 参考値（大枠として使える）
