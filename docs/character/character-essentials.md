# キャラクター重要要素

キャラクターを企画・制作・運用するときの判断基準。新しいキャラを作るときや、AI（CapCut など）にプロンプトを入れるときは、まずこのファイルを参照する。

## キャラに求める要素の言語化

「かわいい」で入り、発見して、キャラクターを理解し、次のどれか（または複数）に至る。

- **憧れる**（こうなりたい）
- **行動の指針にする / 心の支えになる / 自己肯定感を上げる**（このままでいい、本来のポテンシャルがある）
  - 「尊い」もここに入る？（要検討）
- **重ねる**（共感、「この子私みたい」）
- **守る・庇護欲**（応援する、育てる）
- **自分を表す**（アイデンティティ）

> 日本で人気なのは **物語性 × キャラクター**
