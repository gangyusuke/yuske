# コンプライアンスチェックリスト（規約 / 薬機法 / 景品表示法）

> 本ドキュメントは一般的な法規制知識に基づく**参考資料**であり、法律専門家に
> よるレビューを代替するものではない。最終的な合否判断は専門家またはASP・
> 媒体の審査基準に従うこと（→ docs/00_assumptions.md #8）。
> `.claude/agents/compliance-checker.md` はこの一覧を一次チェックに使うが、
> **入稿の最終可否判断は必ず人間が行う**。

## 1. 薬機法（医薬品医療機器等法）NG表現 / 言い換えOK例

本命・サブ案件（求人・VOD・ウォーターサーバー）は薬機法の直接対象ではないが、
将来コスメ・健康系案件を扱う可能性を見据え、汎用チェック表として整備する。

| NG例 | 何が問題か | 言い換えOK例 |
|---|---|---|
| 「シミが消える」「シワがなくなる」 | 医薬品的な効能効果の断定表現（化粧品の効能効果範囲を逸脱） | 「乾燥によるくすみ印象をケア」「ハリのある肌印象へ」 |
| 「痩せる」「脂肪が落ちる」 | 医薬品的な効果を暗示（食品・サプリ等では標榜不可） | 「ダイエットをサポート」「運動と併用した食習慣の見直しに」 |
| 「AGA（薄毛）が治る」「発毛する」 | 医薬品的な治療効果の断定（医薬部外品の範囲を超える） | 「薄毛が気になる方の頭皮環境を整える」 |
| 「〇〇専門医が推奨」（未確認） | 標榜表現の裏付けがない場合は虚偽・誇大表示 | 実際に監修契約がある場合のみ、契約範囲内の表現で「医師監修」と明記 |
| 「絶対に効果が出ます」「100%成功」 | 効果効能の保証表現（薬機法・景表法の両方に抵触） | 「多くの方に実感いただいています（個人の感想です）」 |
| 「副作用なし」「安全性100%」 | 安全性の断定表現 | 「配合成分にこだわっています」（安全性の断定は避ける） |

## 2. 景品表示法（優良誤認・有利誤認）NG表現 / 言い換えOK例

| NG例 | 何が問題か（優良誤認/有利誤認） | 言い換えOK例 |
|---|---|---|
| 「業界No.1」「満足度100%」（根拠なし） | 優良誤認（客観的根拠のない最上級表現） | 根拠となる調査データがあれば出典明記の上で使用。ない場合は「ご好評いただいています」等に留める |
| 「今だけ半額」（実際は常時半額） | 有利誤認（二重価格表示） | 実際にセール前の販売実績期間がある場合のみ、期間・条件を明記して使用 |
| 「完全無料」（実際は条件付き） | 有利誤認（隠れた条件の非表示） | 「〇〇円以上購入で送料無料」など条件を明示 |
| 「〇〇より効果的」（比較対象・根拠不明） | 優良誤認（比較広告の根拠不備） | 自社実績のみを述べる、または明確な比較試験データがある場合のみ出典付きで使用 |
| 「利用者の98%が満足」（サンプル数・調査方法不明） | 優良誤認（根拠不明の統計表示） | 調査主体・期間・母数を明記できる場合のみ使用。不明な場合は使用しない |
| 「今だけ」「本日限り」（実際は常時表示） | 有利誤認（緊急性の偽装） | 実際に期限管理された施策の場合のみ使用し、期限経過後は速やかに表現を変更する |

## 3. 媒体ポリシー事前チェックリスト（Meta / TikTok 共通）

入稿前に `.claude/agents/compliance-checker.md` で機械的に一次チェックし、
**最終判断は人間が行う**。

- [ ] 誇大な効果・収入を保証する表現がないか
- [ ] なりすまし訴求（芸能人・医師・公的機関を騙る表現）がないか
- [ ] Before/After画像を使う場合、誤解を招く演出（過度な加工・条件不記載）がないか
- [ ] LPのファーストビューと広告文言に齟齬がないか（媒体側の「ランディングページの体験」ポリシー）
- [ ] 個人の属性（体型・肌質・収入・宗教・性的指向等）を推定・言及する表現がないか
  （Meta/TikTokともに「個人属性の示唆」を明確に禁止している）
- [ ] 第三者の商標・ロゴ・著作物を無断使用していないか
- [ ] LP上に特定商取引法に基づく表記（事業者名・連絡先・返品条件等）があるか
- [ ] クッキー同意・プライバシーポリシーへの導線があるか
- [ ] 案件個別のASP規約（本命/サブごとにASPへ確認した内容、→ docs/01_offers.md #4）に反していないか

## 4. NGワード早見リスト（クリエイティブ作成時に機械チェックする語彙例）

`compliance-checker` サブエージェントが台本・テロップ内をこのリストと突合する。
リストは初期案であり、実際の審査落ち事例が出るたびに追記していく運用とする。

```
絶対 / 必ず / 100% / 完治 / 治る / 消える / なくなる / 業界No.1 / 満足度No.1 /
今だけ / 本日限り（施策と紐づかない場合） / 誰でも簡単に稼げる / 元本保証 /
確実に儲かる / 医師が本当に驚いた / 〇〇も使ってる（未契約の著名人名）
```

## 5. 運用ルール

1. すべての新規クリエイティブ台本は、入稿前に `.claude/commands/check.md`
   （`/check`）で本チェックリストに基づく一次チェックを通す。
2. 一次チェックで指摘があった場合、人間が最終判断（修正 or 例外許容）を行い、
   判断理由を `data/creatives.csv` の `note` 列に残す。
3. 医療・薬機法対象カテゴリ（AGA・脱毛クリニック等）を将来扱う場合は、
   本ドキュメントの拡充と専門家レビューを追加工程として必須化する。
