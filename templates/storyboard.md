# 絵コンテ雛形

新しい絵コンテを書くときは、このテンプレートをコピーして使う。
映像・音・テロップの3レイヤーを必ず分けて記述すること
（撮影担当と編集担当が分業しても迷わないようにするため）。

```
- creative_id:
- platform: Meta / TikTok
- hook_type（訴求軸）: 問題提起 / 実演 / 比較 / ストーリー / 権威
- hook_text（冒頭2秒フック）:
- 尺（合計）:
- 撮影メモ（場所・小道具・出演者等）:
```

| 区間 | 映像 | 音 | テロップ |
|---|---|---|---|
| 0-2s（フック） | | | |
| 2-5s | | | |
| 5-12s | | | |
| 12-20s | | | |
| CTA | | | |

## 記入ルール
- **映像**：カメラワーク・被写体・カット割りを具体的に（例：「スマホ画面録画、査定フォーム入力操作」）
- **音**：BGMジャンル・SE・声のトーン（例：「明るいUGC系BGM、囁き気味のナレーション」）
- **テロップ**：実際に画面に出すテキストをそのまま記載（NGワードチェック対象になるため、
  最終文言を正確に書くこと。→ docs/02_compliance.md の NGワード早見リストと照合）
- 入稿前に必ず `/check` コマンドでコンプライアンス一次チェックを通すこと
