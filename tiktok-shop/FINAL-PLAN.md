# 最終プラン：0円で始める「買ってよかった雑貨」SNSアフィリエイト

作成：2026-10-12　／　これまでの検討（ジャンル比較・媒体比較・バズる型・高単価案件）をまとめた最終版。
README の「法人設立」「最初の30日プラン」より、このファイルを優先する。

---

## 1. 決まったこと（前提）

| 項目 | 決定 | 理由 |
|---|---|---|
| 事業の形 | **個人のアフィリエイター**（在庫・発送なし） | 運転資金ゼロで始められる |
| 法人 | **稼げてから作る**（下の「法人化の目安」） | 法人は赤字でも年7万円〜の住民税＋税理士代がかかる |
| 広告 | **打たない** | 集客は動画の本数と質（オーガニック）だけ |
| 形式 | **ショート動画（フィード型）**。LIVEはやらない | 本業と両立できる |
| ジャンル | **「買ってよかった」生活雑貨**（約1,000〜5,000円） | 家にある物ですぐ撮れる。規制が低い |
| 顔出し | なし（手元・物撮り） | |
| 差別化 | 「一人暮らし会社員の本音」：自腹・毎日使ってる物だけ・失敗談も正直に | ライバルが多いジャンルなので「誰の買ってよかったか」で勝つ |

## 2. 媒体の組み合わせ（撮影1回 → 投稿先3つ）

| 役割 | 媒体 | 収益 | いつから |
|---|---|---|---|
| **メイン：見つけてもらう** | TikTok | TikTok Shop のカート（アフィリエイト） | フォロワー1,000人から |
| **サブ：同じ動画を再投稿** | Instagram リール | ストーリーズ・プロフィールのリンク | すぐ |
| **リンクのまとめ先** | 楽天ROOM | 楽天アフィリエイト | **すぐ（フォロワー条件なし）** |
| 時々混ぜる高単価 | プロフィールのリンク | 光回線・格安SIM・引越し見積（成果報酬型） | 1,000人以降、自分が使っている物だけ |

- Instagram には TikTok の透かしなしの動画を上げる（CapCut から書き出し）
- 楽天・Amazon・ASP は SNS で使う前に各規約を確認・登録
- **どの媒体でも、アフィリンクを付けたら PR 表記**

### やらないこと
- 債務整理・カードローン・FX/暗号資産・医療脱毛/美容クリニック・情報商材（規制が強い／信用を落とす）
- 不動産売却は単価は高いが、雑貨アカウントとターゲットが違う。やるなら将来、別アカウントで（経験がある場合）
- フォロワー購入・他人の動画の転載・使っていない物のレビュー

## 3. 動画の作り方

**「役に立つ ＋ ちょっと共感/笑い」**。詳細は `viral-formats.md`。

| 型 | 狙い |
|---|---|
| ① 「これ知らん人多すぎ」ライフハック | 保存 |
| ② あるある → 解決（本命） | シェア・コメント＋商品につながる |
| ③ 「いる派？いらない派？」 | コメント |
| ④ 110円 vs 約2,000円 | 最後まで見られる・信頼 |
| ⑤ 使って○か月の本音・失敗談 | 信頼（アフィ化後も効く） |

- 冒頭2秒にテロップで結論か疑問
- 測っていない数字・試していない効果は言わない
- 投稿前に `legal-checker` を通す

## 4. スケジュール

### フェーズ0：準備（今週）
- [ ] 本業の就業規則を確認（副業の可否）
- [ ] **家の棚卸し**：「買ってよかった物」「後悔した物」を15〜20個書き出す（`account-concept.md` の表）
- [ ] TikTok アカウント作成（名前例「一人暮らしの買ってよかった雑貨｜会社員の本音」）
- [ ] Instagram アカウント作成（同じ名前）、楽天ROOM 開設
- [ ] 棚卸し表を Claude に渡す → 台本10本 → 法務チェック → 0円版の撮影リスト

### フェーズ1：型さがし（1〜2週目）
- 週末にまとめ撮り（本を積んで三脚代わり、窓の光、CapCut）
- **1日2本**投稿（昼・夜）、Instagram にも同じ動画
- 5つの型を全部試す（各4本、計20本）
- 紹介した物は楽天ROOMに登録しておく

### フェーズ2：勝ち型に集中（3〜8週目）
- 毎週金曜に `marketer` で振り返り：**保存率・シェア率・コメント数・平均視聴率**
- 伸びた型は「型そのまま、物だけ変えて」3本
- 目標：**8週・約130本でフォロワー1,000人**（保証はない。本数を積む）

### フェーズ3：収益化（1,000人到達後）
- TikTok Shop アフィリエイト登録（条件はアプリ内で最新を確認）
- `affiliate-scout` で、伸びた型に合う商品（手数料10%以上・2,000〜5,000円）を探す。無料サンプルも申請
- 売る動画は**全体の半分以下**。売らない動画も続ける
- 季節の山：**12月中旬〜年末**（大掃除・ギフト）、**2〜3月**（新生活＝一人暮らし雑貨の本番）
- 自分が使っている光回線・SIMがあれば「固定費を下げた話」を時々

### フェーズ4：拡大（月の利益が安定してから）
- 法人化を検討（下の目安）
- 余裕があれば2つ目のアカウント（別ジャンル）

## 5. お金

| | 金額 |
|---|---|
| 初期費用 | **0円**（家にある物・スマホ・無料アプリ） |
| 月の固定費 | 0円 |
| 広告費 | 0円 |
| 1件あたりの報酬（目安） | 3,000円 × 10〜15% ＝ 約300〜450円 |
| 月10万円に必要な数（目安） | 月約290件 ＝ 再生 月30万〜60万回 ＝ 1本平均5,000〜1万回 |

### 税金
- 個人のうちは、副業の所得が年20万円を超えたら確定申告（20万円以下でも住民税の申告は必要）
- 売上・経費（自腹で買った紹介用の物など）は最初から記録しておく（`pl-manager`）

### 法人化の目安
- 副業の利益が**継続して年数百万円規模**になってから、税理士に相談して判断
- それまでは個人で十分。法人化の手順は `README.md` の3章

## 7. 一番大事なこと3つ
1. **家にある物で、今週から投稿を始める**（お金をかけるのは稼げてから）
2. **毎日2本を8週間続ける**（バズは本数の先にある）
3. **本音と PR 表記を守る**（信用が一番の資産）
