# アカウント方針（2026-10-12 決定）

## 前提
- **個人のアフィリエイトクリエイター**として始める（在庫・発送・広告なし）。法人化は月の利益が安定してから
- **運転資金ゼロ・広告なし**。集客は「おすすめ」に載る動画の本数と質だけ
- **フィード型（ショート動画）**中心。LIVEはやらない
- 顔出しなし（手元・物撮り）

## ジャンル
**「買ってよかった」生活雑貨**（約1,000〜5,000円）。キッチン・収納・掃除・デスク周り・バス/洗面・趣味の小物まで含む。

「買ってよかった」はライバルが多いので、**誰の・どんな生活の**買ってよかったかで差をつける。

| 項目 | 内容 |
|---|---|
| 誰の | 会社員の一人暮らし（自分の本当の生活に合わせて変える） |
| 何を | 自腹で買って**毎日使っている**物だけ。失敗した物も正直に出す |
| 価格 | 約1,000〜5,000円（税込） |
| 差別化 | 「使って○か月」の本音、買って後悔した物、100均との比較 |

## アカウント設計（例）
- 名前：「一人暮らしの買ってよかった雑貨｜会社員の本音」
- プロフィール：「自腹で買って毎日使ってる物だけ／失敗した物も正直に／1日2本」
- アイコン：手元か雑貨のイラスト
- 固定する3本：一番伸びた「○選」、失敗談、比較

## 動画の柱（どれが伸びるか最初の2週間で試す）
| 柱 | 例 |
|---|---|
| 買ってよかった○選 | 「一人暮らし1年目で買ってよかった雑貨3選」 |
| 使って○か月の本音 | 「半年使って分かった、良いところと微妙なところ」 |
| 買って後悔 → 買い直し | 「測らずに買って失敗した物」 |
| 100均 vs 少し高い物 | 「110円と約2,000円、毎日使って差が出た」 |
| 場所別 | 「洗面所」「デスク」「玄関」「キッチン」の買ってよかった物 |

キッチン用品の台本10本（`workspace/scripts/2026-10-10-キッチン用品-フォロワー獲得10本.md`）は「キッチンの買ってよかった物」としてそのまま使える。

## 進め方
1. **棚卸し**：家にある「買ってよかった物」「買って後悔した物」を書き出す（下の表）
2. 棚卸し表から `script-writer` が台本10本 → `legal-checker` → `video-producer`（0円版：本で三脚代わり、窓の光）
3. 2週間で20本投稿し、伸びた柱・場所に寄せる
4. 1,000人到達後、`affiliate-scout` で同じ系統の TikTok Shop 商品を探す（無料サンプルも活用）
