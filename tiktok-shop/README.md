# 一人法人 × TikTok Shop 副業 立ち上げキット

社長は自分ひとり。8つの「従業員」は Claude Code のサブエージェント
（`.claude/agents/`）として用意してあります。社長が指示を出し、各エージェントが
`tiktok-shop/workspace/` に成果物を書き出す、という運用です。

> ⚠️ ここにある税務・法務の情報は 2026年10月時点の一般論です。法人設立・決算・
> 契約書は、最終的に税理士・司法書士・行政書士など専門家に確認してください。

---

## 1. 組織図

```
                         社長（あなた）
                    意思決定・最終承認・出品／発送
                              │
     ┌──────────────┬─────────┴─────────┬──────────────┐
  【リサーチ】       【制作】             【販売・集客】     【管理】
  market-analyst    script-writer       poster            pl-manager
  affiliate-scout   video-producer      marketer          legal-checker
```

| エージェント名 | 役割 | 主な成果物（`workspace/` 配下） |
|---|---|---|
| `market-analyst` | 市場アナリスト：トレンド・競合・売れ筋の分析 | `market/` |
| `affiliate-scout` | アフィ探し：高コミッション商品の発掘／協力クリエイター探し | `products/` |
| `script-writer` | 台本・投稿文製作者：動画台本、キャプション、ハッシュタグ | `scripts/` |
| `video-producer` | 動画制作者：絵コンテ、撮影リスト、CapCut編集指示書 | `videos/` |
| `poster` | 投稿者：投稿カレンダー、投稿前チェック、LIVE台本 | `posts/` |
| `marketer` | マーケター：KPI設計、広告（GMV Max等）、伸びた動画の横展開 | `marketing/` |
| `pl-manager` | PL管理：損益表、商品別粗利、資金繰り、経費整理 | `pl/` |
| `legal-checker` | 法務：薬機法・景表法（ステマ規制）・特商法チェック | `legal/` |

**AIにできないこと（社長の仕事）**：実際の撮影・TikTokへの投稿操作・出品登録・
発送・契約の締結・最終判断。エージェントは「下書きと判断材料」を作ります。

### 呼び出し方

Claude Code でこのリポジトリを開き、例えば次のように頼みます。

```
market-analyst で、今週の美容カテゴリの売れ筋を調べて
affiliate-scout で、手数料15%以上・単価3,000円前後の候補を5つ出して
script-writer で products/2026-10-美容.md の1位商品の15秒台本を3パターン
legal-checker で scripts/ の最新台本をチェックして
pl-manager で今月の売上CSVから損益表を更新して
```

## 2. 週次の業務フロー

| 曜日 | 担当 | やること |
|---|---|---|
| 月 | market-analyst → affiliate-scout | トレンド分析 → 今週扱う商品を3〜5個に絞る |
| 火 | script-writer → **legal-checker** | 台本を1商品3パターン作成 → 表現チェック（NGは差し戻し） |
| 水〜木 | video-producer → 社長 | 絵コンテ・撮影リスト作成 → 社長が撮影・編集 |
| 毎日 | poster → 社長 | 投稿カレンダーどおりに社長が投稿（1日1〜3本） |
| 金 | marketer | 再生数・CTR・CVRを集計、伸びた型を翌週に横展開 |
| 月末 | pl-manager | 月次損益・資金繰り・経費整理、税理士への資料準備 |

**鉄則：投稿前に必ず `legal-checker` を通す。** 健康食品・化粧品の誇大表現と
「PR」表記漏れは、アカウント停止や行政処分に直結します。

## 3. 法人設立ロードマップ（副業として）

### 3-1. 株式会社か合同会社か

| | 合同会社（LLC） | 株式会社 |
|---|---|---|
| 設立実費の目安 | 約6万円（登録免許税6万円。電子定款なら印紙代0円） | 約20〜25万円（登録免許税15万円＋定款認証3〜5万円） |
| 定款認証 | 不要 | 必要（公証役場） |
| 役員任期 | なし | 最長10年（更新登記が必要） |
| 決算公告 | 義務なし | 義務あり |
| 向いている人 | **コスト重視の一人副業法人（おすすめ）** | 将来の資金調達・対外的信用を重視する人 |

### 3-2. 手順

1. **本業の就業規則を確認**（副業・兼業・役員就任の可否）
2. 会社の基本事項を決める：商号／本店所在地（自宅可か賃貸契約を確認、
   バーチャルオフィスも可）／事業目的（下記）／資本金／決算月
3. 法人の実印を作る
4. 定款作成（電子定款なら印紙代4万円が不要。freee会社設立・マネーフォワード会社設立が便利）
5. 資本金の払い込み（個人口座に入金し、通帳コピーを用意）
6. 法務局で設立登記 → 登記日が設立日
7. 設立後の届出
   - 税務署：法人設立届出書、**青色申告の承認申請書**、給与支払事務所等の開設届出書
   - 都道府県税事務所・市区町村：法人設立届
   - 年金事務所：役員報酬を払う場合は社会保険の新規適用届（下記注意）
   - **適格請求書（インボイス）発行事業者登録**：取引先・プラットフォームとの関係で判断
8. 法人口座の開設（ネット銀行が早い）、法人カードの作成
9. **TikTok Shop セラー登録**（法人として登記簿・本人確認書類・口座等を提出し審査）
10. 会計ソフト導入（freee / マネーフォワード）、税理士の目星をつける

**事業目的の記載例**（定款）

```
1. インターネットを利用した各種商品の企画、製造、販売及び輸出入
2. ソーシャルメディアを活用した広告、宣伝、マーケティング業務の受託
3. アフィリエイトプログラムに関する業務
4. 動画コンテンツの企画、制作、配信
5. 前各号に附帯関連する一切の事業
```
扱う商品に許認可が必要な場合（中古品＝古物商許可、食品の製造・小分け、
化粧品の製造販売・輸入など）は、目的への追記と許認可の取得が必要です。

### 3-3. 副業法人ならではの注意点

- **役員報酬を払うと社会保険の加入義務**が出て、本業の会社と合算手続き
  （二以上事業所勤務届）になり、本業にも知られます。最初は**役員報酬0円**で
  始め、利益は会社に残すのが一般的です。
- **赤字でも法人住民税の均等割（年7万円程度〜）がかかる**。固定費として計上を。
- 法人の決算・申告は個人の確定申告より複雑。初年度から税理士に頼むと安心
  （年10〜30万円程度が目安）。
- 個人の確定申告も引き続き必要（本業の給与＋法人からの収入があれば）。
- **個人と法人のお金を混ぜない**。立替は必ず精算書を残す。

## 4. TikTok Shop で必ず押さえる法規制

| 法律 | 何がダメか | 例 |
|---|---|---|
| 景品表示法（ステマ規制、2023年10月〜） | 広告なのに広告と分からない表示 | 提供品・アフィ案件で「PR」「広告」表記なし |
| 景品表示法（優良誤認・有利誤認） | 実際より著しく良く見せる／お得に見せる | 根拠のない「No.1」、常時やっている「今だけ半額」 |
| 薬機法 | 化粧品・健康食品で医薬品的な効能をうたう | 「シミが消える」「飲むだけで痩せる」「アトピーが治る」 |
| 特定商取引法 | 通信販売の表示義務 | 事業者名・住所・返品条件の記載漏れ |
| 著作権・肖像権 | 他人の音源・映像・人物の無断使用 | 商用利用不可の音源をショップ動画に使用 |

## 5. 最初の30日プラン

| 週 | ゴール |
|---|---|
| 1週目 | 就業規則確認、会社形態・商号・決算月を決定、定款作成 |
| 2週目 | 登記申請、待っている間に TikTok アカウントを個人で育成開始（毎日投稿） |
| 3週目 | 届出・法人口座開設・TikTok Shop セラー／アフィリエイト登録申請 |
| 4週目 | 商品3つで台本→撮影→投稿を回し、`marketer` と `pl-manager` で初回振り返り |

数値目標の初期値（`marketer` が実績に合わせて更新）：
- 投稿数：1日1〜3本、月60本
- 平均再生数 1,000回 → 商品ページ遷移率 1〜3% → 購入率 2〜5%
